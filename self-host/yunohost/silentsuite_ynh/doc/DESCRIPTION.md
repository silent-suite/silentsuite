SilentSuite keeps your calendar, contacts, tasks and notes end-to-end encrypted. Your data is encrypted in your browser or on your phone before it reaches this server, so the server only stores ciphertext.

This package runs the SilentSuite server (an Etebase-compatible sync server) and the SilentSuite web app. The Android app and the SilentSuite Bridge (for CalDAV/CardDAV desktop clients) can sync with it too.
