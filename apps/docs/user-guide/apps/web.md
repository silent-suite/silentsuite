# SilentSuite Web

The SilentSuite web app runs in any modern browser at [app.silentsuite.io](https://app.silentsuite.io). You can also install it, so it opens in its own window with its own icon in your dock, taskbar, app launcher, or home screen.

Installing does not create a new account. You sign in with the same email and password, and your data stays end-to-end encrypted. If you use a self-hosted server, the steps are the same.

## Install on a computer

### Chrome

1. Open [app.silentsuite.io](https://app.silentsuite.io).
2. At the top right of the address bar, select **Install**.
3. Follow the on-screen instructions.

If you don't see **Install** in the address bar, select **More**, then **Cast, save, and share**, then **Install SilentSuite...**.

### Microsoft Edge

1. Open [app.silentsuite.io](https://app.silentsuite.io).
2. At the right of the address bar, select the **App available** icon. The label shows for a moment, then only the icon stays.
3. Select **Install**.

If you don't see the icon, select **Settings and more**, then **Apps**, then **Install SilentSuite**.

### Safari on a Mac

This needs macOS Sonoma 14 or later.

1. Open [app.silentsuite.io](https://app.silentsuite.io).
2. From the menu bar, choose **File**, then **Add to Dock**.
3. Click **Add**.

### Firefox

This needs Firefox 143 or later on Windows. On a Microsoft Store install of Firefox, it needs Firefox 150 or later. Firefox does not offer this on macOS or Linux, so use another browser there or keep using SilentSuite in a Firefox tab.

1. Open [app.silentsuite.io](https://app.silentsuite.io) in a normal window, not a private one.
2. In the address bar, click the **Add tab to taskbar** icon.
3. A new window opens and asks whether to pin it to the taskbar.

## Install on Android

### Chrome

1. Open [app.silentsuite.io](https://app.silentsuite.io).
2. To the right of the address bar, tap **More**.
3. Tap **Install and create shortcut**.
4. Tap **Install** and follow the on-screen instructions.

### Firefox

1. Open [app.silentsuite.io](https://app.silentsuite.io).
2. Open the browser menu and tap **More**.
3. Tap **Add app to Home screen**.
4. In the panel that opens from the bottom of the screen, tap **Add to home screen**.

For your calendar, contacts, and tasks in Android's own apps, use [SilentSuite for Android](./android.md) instead. It syncs your data into those apps, which the web app does not do.

## Install on iPhone or iPad

Use Safari.

### iPhone

1. Open [app.silentsuite.io](https://app.silentsuite.io).
2. Tap the **Share** button. If you don't see it, tap the **More** button first, then **Share**. On iOS 27, tap the **Page Menu** button at the left of the address bar instead of **More**.
3. Scroll down the list and tap **Add to Home Screen**. On iOS 27, tap **View More** first. If it's missing, scroll to the bottom of the list, tap **Edit Actions**, then tap **Add to Home Screen**.
4. On iOS 26 or later, leave **Open as Web App** turned on.
5. Tap **Add**.

### iPad

1. Open [app.silentsuite.io](https://app.silentsuite.io).
2. Tap the **Share** button. On iPadOS 26 tap **More** next, and on iPadOS 27 tap **View More**.
3. Tap **Add to Home Screen**.
4. On iPadOS 26 or later, leave **Open as Web App** turned on.
5. Tap **Add**.

The installed web app does not sync SilentSuite data into the native iOS Calendar, Contacts, or Reminders apps. See [SilentSuite for iOS](./ios.md) for what is on the roadmap.
