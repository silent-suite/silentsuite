# SilentSuite for iOS

## Planned

SilentSuite does not support iOS native sync yet. A native SilentSuite app for iPhone and iPad is planned, but its scope and timing haven't been decided. The EteSync iOS app is not a supported or working SilentSuite client, so do not use its setup instructions with a hosted or self-hosted SilentSuite account.

## What works today

You can use the [SilentSuite web app](https://app.silentsuite.io) in a browser on iPhone or iPad, and [add it to your Home Screen](./web.md#install-on-iphone-or-ipad). This does not sync SilentSuite data into the native iOS Calendar, Contacts, or Reminders apps.

On a Mac, the [SilentSuite DAV Bridge](./dav-bridge.md) connects supported desktop apps such as Apple Calendar and Contacts. The Bridge is a desktop option and does not run on iPhone or iPad.

We will publish tested installation and migration instructions here when native iOS support is ready.
